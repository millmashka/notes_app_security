# Настройки безопасности PostgreSQL
1. В файле pg_hba.conf разрешено подключение только с localhost.
2. Используется метод аутентификации md5 для пользователей.
3. Включен SSL (если доступно).
4. Отключён доступ без пароля.
5. Назначены роли:
   - admin_user — имеет права CREATE, ALTER
   - app_user — имеет права SELECT, INSERT, UPDATE, DELETE
