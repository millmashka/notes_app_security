# План безопасности приложения Notes App

## 1. Цели и требования безопасности

- Защита пользовательских данных (логин, пароль, заметки)
- Исключение утечек через debug-режим
- Защита от SQL-инъекций и XSS
- Минимизация прав доступа к базе данных

## 2. Оценка угроз

- Возможность SQL-инъекций при вводе данных
- Угроза при `debug=True`
- Утечка паролей при отсутствии хэширования
- Ненадёжное подключение к PostgreSQL

## 3. Реализованные меры защиты

- Пароли хэшируются (bcrypt)
- Переменные окружения хранятся в `.env`
- `debug=False`
- В PostgreSQL:
  - включено `hostssl`
  - метод аутентификации `md5`
  - доступ только для пользователя приложения
  - `listen_addresses = 'localhost'`

## 4. План регулярного тестирования

- **SAST**: Bandit при каждом push
- **DAST**: тестирование OWASP ZAP перед релизом
- **Пентест**: раз в месяц
